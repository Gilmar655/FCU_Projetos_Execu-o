Seu painel pronto para consulta.

O pacote contém o site completo e as 15 abas da base FCU. Extraia a pasta inteira e abra index.html.

Publicar no GitHub

  1. Na sua conta, crie o repositório FCU_Projetos_Execucao.
  2. Envie os arquivos e a pasta assets para a raiz do repositório. O arquivo index.html precisa ficar na raiz. Não envie apenas o ZIP.
  3. Abra Settings → Pages. Selecione Deploy from a branch → main → /(root) → Save.
  4. Aguarde a publicação e use o endereço informado pelo GitHub Pages para divulgar a consulta.
Criar repositório no GitHub ↗

O site foi preparado, mas ainda não está publicado. A integração disponível não permite criar repositórios nem ativar o GitHub Pages.

Consultar as informações

Use os filtros do painel para selecionar contratada, polo, intervenção, situação, criticidade e período. A busca localiza projeto, ordem, circuito, comentários e outros campos.

Na área Planilhas para consulta, escolha qualquer aba. A tabela exibe todas as colunas com rolagem lateral. Clique nos cabeçalhos para ordenar e em um projeto para abrir o registro completo.

Importar e compartilhar uma atualização

  1. Clique em Importar base e selecione Excel (.xlsx) ou CSV. A importação atualiza e, quando permitido, salva a consulta neste navegador.
  2. Para atualizar todos os visitantes, clique em Exportar dados → Base para publicar · data.js.
  3. Substitua o data.js na raiz do repositório pelo novo arquivo e aguarde o GitHub Pages atualizar.

A importação local não envia arquivos ao GitHub. Para abandonar uma importação local, use Restaurar base incluída no site.

Exportar a base ou um recorte

Excel completo mantém o arquivo Excel carregado, incluindo todas as abas. Consulta atual, em Excel ou CSV, exporta todas as linhas filtradas e colunas da aba selecionada.

Entender os indicadores

A base tem 5.188 programações de 2.332 projetos. A execução integral considera apenas “Executado”; a execução parcial aparece separadamente. Os resumos originais conservam os valores do Excel e não são recalculados pelos filtros do painel.

O relógio mostra a hora atual de Brasília. A referência do arquivo é 13/09/2026, com programações de janeiro a outubro de 2026.
