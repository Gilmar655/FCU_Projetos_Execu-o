EXPORTAÇÃO

Leve os dados com você

A consulta exporta as linhas filtradas da aba selecionada. A opção Excel completo baixa o arquivo original da base publicada.

Para atualizar os dados de todos os visitantes, substitua o data.js no repositório pela base exportada.
ATUALIZAR DADOS

Importar uma nova base

Carregue Excel (.xlsx) ou CSV com cabeçalho. A nova base substitui a consulta neste navegador.

A importação é local. Para compartilhar a atualização, exporte “Base para publicar” e substitua o data.js no GitHub.
